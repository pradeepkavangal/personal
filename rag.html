What is happening?

RAG combines two major phases: indexing and query-time retrieval/generation.

Indexing: Documents → chunks → embeddings → vector database
Query time: User question → query embedding → similarity search → Top-K chunks → augmented prompt → LLM → answer
Important: The query usually isn't broken into chunks. Instead, the complete query is converted into an embedding vector and compared against the vectors representing document chunks.
